# مراجعة نصوص «سطر برو» — المرحلة 0

> للقائد: قراءة بعين كاتب تسويق يخاطب **غير المطور العربي** (طالب/صاحب متجر).  
> الهدف: الإقناع بالإمكان لا بالراحة، والصدق قبل الإثارة.

## 1. حكم عام

### أين تقنع
- «اشتراك واحد بالريال» يلغي حاجز البطاقة الأجنبية — هذه القيمة الأولى لغير المطور.
- «لا مفاتيح تجهّزها» يترجم الراحة بلغة يومية.
- «لا نستخدم بريدك لغير ذلك» يبني ثقة فورية في صفحة حجز مبكر.

### أين تتعثر
- «BYOK» و«مفاتيح API» مصطلحات تقنية لا يفهمها صاحب المتجر العادي؛ تبدو حاجزاً لا ميزة.
- «النماذج والتوليد» قد تُفهم على أنها للمطورين أكثر من التجار.
- «سقوط لمفاتيحك» استعارة غامضة: هل يعني فقدان البيانات أم مجرد عودة للمجاني؟

### بدائل مصطلحية مقترحة
- بدلاً من «BYOK / مفاتيح API»: «مفاتيحك الخاصة» أو «حسابك عند المزوّد».
- بدلاً من «سقوط لمفاتيحك»: «ترجع للمجاني تلقائياً» أو «لا تضيع مشاريعك».

## 2. بدائل للعنوان الرئيسي

| البديل | السبب |
|---|---|
| «ابنِ فكرتك باشتراك واحد بالريال.» | يترجم «فكرة ⇒ منتج» ويحتفظ بالوعد الملموس. |
| «منتجك الرقمي يبدأ من سطر واحد.» | يربط الاسم بالنتيجة بدلاً من الآلية. |
| «ذكاء اصطناعي يعمل لك — بالريال وبلا إعداد.» | يوضح القيمة والتميز الإقليمي معاً. |

## 3. بدائل لنص الزر

| البديل | السبب |
|---|---|
| «احجز مكانك المؤسسي» | يوحي بالندرة والأولوية أكثر من مجرد اهتمام. |
| «أرسل لي العرض أولاً» | يخاطب غير المطور الذي لا يريد التزاماً الآن. |

## 4. اقتراحات صياغة بندية (قبل / بعد)

**البند الأول — ابدأ بلا أي إعداد**
- قبل: «ابدأ بلا أي إعداد»
- بعد: «ابدأ بإعداد صفر — نجهّز كل شيء لك»
- السبب: يُبرز أن المستخدم لا يدفع فقط، بل يُحوّل العمل إلى التطبيق.

**البند الرابع — السقوط للمجاني**
- قبل: «لا تُحبس أبداً (سقوط لمفاتيحك)»
- بعد: «رصيدك ينتهي؟ ترجع للمجاني بمفتاحك دون فقدان شيء»
- السبب: يُزيل الغموض ويُحوّل التهديد إلى ضمان.

**فقرة الصدق**
- قبل: «برو لا يشمل اشتراكات Claude Code وCodex وKimi Code الأصلية»
- بعد: «سطر برو يغطي النماذج والتوليد داخل التطبيق؛ اشتراكات Claude Code وCodex وKimi Code تبقى عندك كما هي»
- السبب: يُفصل ما هو مشمول عمّا هو مستثنى دون إيحاء بالنقص.

## 5. قيود صدق غير قابلة للمساس

في أي صياغة مقترحة، هذه الخطوط حمراء:
- لا «غير محدود» ولا «غير محدودة».
- لا «جميع النماذج» ولا «كل المحركات».
- لا وعد بالنشر كأنه متاح اليوم؛ يبقى «قيد البناء» أو «قادم».
- لا ادعاء بأن الاشتراك يشمل Claude Code / Codex / Kimi Code الأصلية.

أي اقتراح يخالف هذه القيود مرفوض سلفاً.
