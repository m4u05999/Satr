## دروس عابرة للمحرّكات (مثبتة، من `D:\sater\executor.ps1`)

1. **البرومبت العربي عبر الوسيطة خطر.** فضّل stdin حيث يُقبل (codex، claude)؛ ومع kimi
   هرّب `"` بنفسك.
2. **الأنبوب في PowerShell 5.1 ليس UTF-8.** استعمل `Out-File -Encoding utf8` أو
   `Tee-Object` ثم اقرأ بـ`iconv -f UTF-16LE` (‏`OBS-042`).
3. **`2>&1` على ملف تنفيذي أصلي يقلب `$?` إلى false رغم رمز الخروج 0** (‏PowerShell 5.1
   يغلّف stderr في `NativeCommandError`). لذلك يعتمد «سطر» رمز الخروج مصدراً للحقيقة
   ويكتفي بتنبيه جانبي حين تخالفه الصدفة — انظر `term.js:runCaptureNow`.
4. **صياغة cmd لا تعمل في طرفية «سطر»** (‏PowerShell): `cd /d ... && ...` يفشل صامتاً
   فتبدو المهمة حيّة بلا أثر (‏`OBS-042`).
