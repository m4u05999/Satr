# سطر 2.9.3

## الإصلاحات

- يتعرف TestSprite الآن على صيغ عربية طبيعية مثل «أنا أريد إختبار» و«أنا أبغى أختبر».
- يطبّع همزات العربية والتشكيل قبل تصنيف نية الاختبار، مع عدم تفعيل الأسئلة التفسيرية.
- يفحص أول التشغيل `claude auth status` بأمان ويمنع محرك Claude عند تسجيل الخروج.
- تعرض البوابة أمر `claude auth login` ورسالة واضحة عند انتهاء جلسة OAuth.
- لا يعيد فحص المصادقة أي token أو قيمة سرية إلى الواجهة.

## التحقق

- `npm run test:testsprite-ready`: ناجح وصفر أخطاء CSP/console في harness الحي.
- `npm run test:claude-auth`: ناجح.
- `npm run test:full`: نجحت 19/19 مجموعة، مع مجموعتين خارجيتين مستبعدتين عمداً.
- smoke test للحزمة: نجح الإصدار وكاشف TestSprite وبوابة Claude auth و`node-pty` من `app.asar`.
