نجح DPAPI الحقيقي سابقاً بنواة التوصيلات المبنية ونقل ورمز اصطناعيين: المصادقة واختيار المورد وفك التشفير واختبار الخدمة والفصل وعدم ظهور الرمز أو الحساب مكشوفين. ملفات تلك النواة مطابقة أيضاً في الحزمة الحالية؛ الدليل dist/final-batch-dpapi-evidence.json. لم يُعد هذا المسبار بعد تغيير أصول PWA، ولم يكن اختبار حساب مزود حي.

الحراس السابقة لا تثبت هاتفاً فعلياً أو قبول شهادة أو Web Push أو وسيطاً منشوراً؛ الاقتران والمحركات وPWA اختُبرت حياً لاحقاً كما في التقرير أعلاه. لم يُختبر Linux أو مخزن شبكي فعلياً. OAuth العامة غير مكتملة؛ هذه دفعة PAT الشخصية.
