# سطر 2.9.2

## الجديد

- يكفي قول «أريد اختبار» لبدء رحلة TestSprite عند ضبط المفتاح.
- يسأل الوكيل عن نطاق الاختبار وتسجيل الدخول وسياسة معالجة الإخفاقات عندما تكون التفاصيل ناقصة.
- يعرض «سطر» حالات تجهيز TestSprite وتقدمه واكتماله داخل الواجهة.
- يعتمد اكتشاف الانتهاء على تحديث `test_results.json` ووصول الحالات إلى حالة نهائية، لا على خروج غلاف CLI.
- يدعم Web harness تلقائياً في مساري Codex وSDK مع تنظيف المفتاح من الملفات المؤقتة.
- يستثني تقارير TestSprite الخارجية المولدة من حارس CSP الخاص بأصول Electron.

## التحقق

- `npm run test:testsprite-ready`: ناجح، بما فيه اختبار Electron الحي وصفر أخطاء CSP/console.
- `npm run test:full`: نجحت 18/18 مجموعة، مع مجموعتين خارجيتين مستبعدتين عمداً.
- smoke test للحزمة: نجح تحميل الإصدار وتكامل TestSprite و`node-pty` من `app.asar`.
