# النسخ أثناء تسجيل الدخول ونافذة Chrome البيضاء

## النتيجة وحدودها

أُصلح قطع الأمر عند نسخ تحديد من الطرفية. لم يُثبت سبب نافذة Chrome البيضاء، ولم يُعدّل مسار فتح المتصفح أو إعدادات Chrome. لا يُعد هذا التقرير نجاحاً لتسجيل الدخول، ولا قبولاً بشرياً، ولا إصداراً جديداً. طلب المالك جمع الإصلاحات قبل التصدير وإيقاف تكرار الاختبار اليدوي.

## إصلاح مثبت في المصدر

كان معالج حقل الطرفية يفرّغ الحقل ويرسل `\x03` عند كل Ctrl+C ولو كان النص محدداً. كما لم يوجد اعتراض للنسخ قبل معالج xterm. الآن يسبق معالجٌ في مرحلة capture كليهما: يحافظ على النسخ الأصلي لتحديد الحقل، وينسخ تحديد خرج التبويب النشط في BiDi أو xterm عبر الحافظة. التحديد خارج التبويب لا يمنع القطع. فشل الحافظة يعرض تنبيهاً ولا يتحول إلى إشارة قطع. بلا تحديد يبقى السلوك السابق.

الحارس `npm run test:terminal-tabs` يستعمل مكوّن الإنتاج وxterm الحقيقيين داخل Electron، وأحداث مفاتيح وتحديد DOM حقيقيين؛ يستبدل منفذ الحافظة وPTY بمسجّلين داخل الصفحة. لذلك يثبت عدم إرسال إشارة القطع وصحة النص المرسل للحافظة، ولا يدّعي اختبار حافظة النظام أو خدمة Anthropic. يغطي أيضاً فشل الحافظة والتحديد خارج الطرفية. نجح دون مخالفات CSP.

## عضّات الحارس

الأمر المنفّذ للزرع والفحص والاستعادة: `node dist/terminal-copy-bites.cjs`.
السكربت يحفظ بايتات المصدر، ويطبّق كل استبدال أدناه بـ `fs.writeFileSync(file, source.replace(before, after))`، ثم يعيد قراءته ويعدّ الأصل والمتحور قبل تشغيل `electron scripts/terminal-tabs-test.js`. الاستعادة بعد كل فحص في `finally`: `fs.writeFileSync(file, original)`؛ طابقت البايتات الأصل في الحالات الثلاث (`restored:true`).

| الزرع | العدّ قبل: الأصل/المتحور | العدّ بعد: الأصل/المتحور | رمز الخروج |
|---|---|---|---|
| استبدال شرط تحديد الحقل بـ `false /* copy-input mutation */` | 1 / 0 | 0 / 1 | 1 |
| استبدال `? selection.toString() : ''` بـ `? '' /* copy-output mutation */ : ''` | 1 / 0 | 0 / 1 | 1 |
| استبدال `active.term.getSelection()` بـ `'' /* copy-grid mutation */` | 1 / 0 | 0 / 1 | 1 |

رسائل الفشل الحرفية:

```text
terminal-tabs: AssertionError [ERR_ASSERTION]: Error: COPY_INPUT_INTERRUPTED: Ctrl+C with an input selection must preserve native copy and PTY.
terminal-tabs: AssertionError [ERR_ASSERTION]: Error: COPY_OUTPUT_INTERRUPTED: copying selected terminal output must not interrupt PTY.
terminal-tabs: AssertionError [ERR_ASSERTION]: Error: COPY_GRID_INTERRUPTED: copying xterm selection must not interrupt PTY.
```

الأدلة المحلية الخام: `dist/terminal-copy-bite-input.json` و`dist/terminal-copy-bite-output.json` و`dist/terminal-copy-bite-grid.json`.

## تقصّي Chrome: مشاهدات وليست تشخيصاً نهائياً

- أخبر المالك أن فتح الرابط يدوياً في نافذة Chrome معتادة وصل إلى تسجيل الدخول. ظهر أيضاً خطأ 400 بعد إدخال كود؛ لا دليل محفوظ على نجاح تبادل الكود في تلك المحاولة.
- Claude المثبت 2.1.280 يستدعي في مسار ويندوز الافتراضي `rundll32` بوسيطَي `url,OpenURL` والرابط، ويدعم تجاوزاً عبر `BROWSER`. مسار تسجيل الدخول في بوابة سطر يرسل `claude auth login` إلى الطرفية، ولا يفتح Chrome بنفسه.
- فحص بيئة طرفية سطر لم يجد `BROWSER` أو `CHROME_CRASHPAD_PIPE_NAME` أو `CHROME_VERSION`. لم تُطبع أسرار. لا يثبت هذا تطابق بيئة كل محاولة سابقة.
- Chrome المثبت 153.0.8010.50؛ معالج ChromeHTML المسجل يشير إلى `chrome.exe --single-argument %1`، ولم يظهر تجاوز DelegateExecute في المفتاح المقروء.
- الملف المعتاد يحتوي ثمانية ملفات شخصية و`picker_shown:true`؛ ذلك لا يثبت أن نافذة اختيار الملف هي مصدر البياض. التجربة المعزولة تحتوي ملفاً واحداً.
- عند فحص النوافذ المفتوحة عبر computer-use لم تكن النافذة البيضاء موجودة؛ ظهرت نافذتا Chrome عاديتان فقط. لم تُنقل كلمات مرور أو رموز، ولم تُغيّر الملفات الشخصية أو مفاتيح التسجيل أو إعدادات الرسوميات.

البحث العام لم يعطِ علة موثوقة تطابق هذه الحالة. لا مبرر مثبت لفرض ملف Chrome معين أو تعطيل GPU أو تغيير المتصفح الافتراضي. يبقى المطلوب دليلاً من مسار الإطلاق وقت ظهور النافذة البيضاء، لا إعادة تجربة تسجيل الدخول بالكود نفسه بعد إنهاء عمليته.

### متابعة السجلات

في متابعة 2026-09-23 لم يعرض فحص أحداث Application ذات الأرقام 1000 و1001 و1002 خلال ثلاثة أيام حدثاً مطابقاً لـchrome.exe. لم يوجد chrome_debug.log في الملف المعتاد أو المعزول. مجلد Crashpad المعزول فارغ؛ تقارير الملف المعتاد الثلاثة مؤرخة في 2025-12-25 و2026-06-06 و2026-06-17، فتسبق الواقعة ولا تصلح دليلاً عليها. اقتصر الفحص على بيانات الملفات الوصفية دون قراءة محتوى تفريغات الذاكرة. ظهر في تعداد النوافذ Chrome عادي واحد، ولم تكن النافذة البيضاء موجودة. غياب تقرير تعطل لا ينفي تعليق نافذة حية.

قيد إعادة الإنتاج: تعليمات أدوات الجلسة تحظر إطلاق متصفح خارجي للتصفح، وتسمح بالمعاينة داخل سطر. لذلك لا تُعاد محاولة إطلاق Chrome عبر shell أو أداة بديلة لتجاوز القيد. الفحص التالي يحتاج أن تكون النافذة المبلّغ عنها مفتوحة؛ فتح صفحة المصادقة ليس إثباتاً لإكمال تسجيل الدخول.
