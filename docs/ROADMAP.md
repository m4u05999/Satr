# خريطة تطوير «سطر» — الدفعات 1–4 (اعتُمدت 2026-07-09) + الدفعة 5 (اعتُمدت 2026-07-11)

> من تحليل SWOT شامل + مصفوفة فجوة مقابل Cursor (جلسة 2026-07-09، بموافقة المالك).
> **التموضع المعتمد**: «رفيق البرمجة العربي لكل النماذج» — محادثة + طرفية + عارض + وكيل.
> **ليس** استنساخ IDE. لا نطارد Tab-completion ولا محرّراً كاملاً — نطوّق نقطة عمى Cursor
> (العربية) ونمتلك حلقة وكيل متعددة النماذج.
> منهجية التنفيذ الثابتة: مرحلة فرعية واحدة في الدور، تحقق حيّ قبل البناء، قبول المالك
> بـ npm start بعد كلٍّ، تحديث التوثيق مع كل عقد جديد.

---

## خلاصة الفجوة مقابل Cursor (مثبّتة)

- **فجوتنا الجوهرية**: Cursor «يرى ويلمس الكود» (محرّر + وكيل لأي نموذج + فهرسة)؛
  «سطر» يفعلها عبر عيون Claude فقط، ومحوّلات REST (Gemini/DeepSeek/Qwen) **دردشة عمياء**
  (لا ترى ملفات، لا تحرّر، لا أدوات).
- **تفوّقنا**: طرفية BiDi عربية (مكسورة في Cursor)، تجربة عربية كاملة، أذونات حيّة عربية،
  تعدد نماذج رخيص، مجاني ومفتوح.
- ⚫ خارج التموضع (قرار): Tab completion، محرّر كامل، فهرسة embeddings عميقة.

## الدفعة 1 — «النموذج يرى المشروع» (الحالية)

> الأثر: فوري ومرئي؛ المخاطرة: صغيرة. تحوّل المحوّلات من «دردشة عمياء» إلى «تفهم مشروعك».

- **1.1 — حقن @الملفات للمحوّلات**: عند إرسال رسالة فيها `@مسار` بمحرك غير SDK، يقرأ
  main.js محتوى الملف (بسقف حجم) ويحقنه في البرومبت المُرسَل للمحوّل بصيغة واضحة
  (اسم الملف + محتواه في كتلة كود). Claude/SDK لا يتأثر (يقرأ بنفسه).
  تنقية: المسار داخل cwd حصراً (لا `..`)، سقف حجم لكل ملف وسقف إجمالي.
  **قبول**: `@src/index.html اشرح هذا الملف` مع DeepSeek يشرح المحتوى الفعلي.
- **1.2 — لوحة ملفات/عارض قراءة خفيف**: شجرة ملفات جانبية (تعيد استخدام `files.js`
  القائم) + النقر يفتح **عارض قراءة** (ليس محرّراً) بتظليل بسيط، الكود LTR داخل RTL.
  زر 📄 في الشريط العلوي (ليس أمر `/` — احتراماً لتجميد الأوامر).
  **قبول**: أتصفح شجرة مشروعي وأفتح ملفاً وأقرؤه بوضوح.
- **1.3 — ذاكرة المحوّلات على القرص**: سجل محادثات REST يُحفظ في `~/.satr/chats/`
  (بدل الخريطة في الذاكرة التي تُمسح بإعادة التشغيل) + استئناف بعد إعادة التشغيل.
  **قبول**: أحادث DeepSeek، أغلق «سطر»، أفتحه، أكمل المحادثة بذاكرتها.

  جديد يرث الوكيل كاملاً.
