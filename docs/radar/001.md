### نصّ Anthropic الحالي: مطوّرو Agent SDK «ينبغي» أن يستعملوا مفاتيح API — ولا يُسمح بتمرير اشتراك Pro/Max عبر تطبيق طرف ثالث

*F1 · Anthropic* — `current text`

صفحة Legal and compliance في وثائق Claude Code تقول حرفياً: «Developers building products or services that interact with Claude's capabilities, including those using the Agent SDK, should use API key authentication… Anthropic does not permit third-party developers to offer Claude.ai login into their own applications, or to route requests through Free, Pro, or Max plan credentials on behalf of their users. Moreover, developers may not collect, store, or intermediate Claude.ai credentials or session tokens.» والاستثناء الصريح: «Nor does it prevent an end user from signing in to the unmodified Claude Code binary with their own Claude subscription.» لم أجد تغييراً في هذا النص خلال ٦٠ يوماً — لكنه لم يكن مسجّلاً في OBS.

- **لماذا**: مسار `claude-agent-sdk` باشتراك المستخدم هو المنطقة الرمادية بالضبط؛ مسار `claude-cli` (binary غير معدّل + تسجيل دخول Anthropic نفسه) هو الآمن تعاقدياً. أي كود في سطر يلمس session tokens يخالف النص حرفياً.
- **الإجراء**: مراجعة تدفّق المصادقة: هل يلمس سطر التوكن؟ هل يمكن جعل `claude-cli` المسار الافتراضي للاشتراكات و`SDK` لمفاتيح API؟ وتوثيق الموقف في README قبل أن يسأل أحد.
