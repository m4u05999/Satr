### المسار والعقد

- تضيف بوابات المتصفح في agent.js وcodex.js وkimi.js الحقل الاختياري permissionReasons

  يمكن أن يجتمع أكثر من سبب؛ مجموع عدادات الأسباب ليس عدد البطاقات.
- main.js يسجّل الطلب بعد مرشح ملكية الدور، ثم يقيس الرد المقبول عبر بوابة المقابض المشتركة
  لسطح المكتب والجوال. إغلاق SDK المتزامن أثناء معالجة الرد لا يُحسب إلغاءً قبل حسم الرد.
- إغلاق طلب SDK أو مالك Query يسجّل cancelled؛ نتيجة SDK وحدها لا تغلق أذونات الوكلاء الخلفيين.
  نهاية result/proc_done/spawn_error لغير SDK تغلق طلبات الدور، حتى لو أصبح حدث النهاية قديماً.
- preload يكشف window.satr.permissionMetrics() فقط، بلا مدخلات، عبر satr:permissionMetrics.
  اللقطة schema_version:1، scope:main_chat_issued_requests، وwindow:last_completed.
