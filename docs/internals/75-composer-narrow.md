# 75 — المؤلّف في عمود الدردشة الضيّق: منتقي المحرك وشريط الوعي (‏OBS-168/174 — 2026-09-12)

الدفعة (د) من جولة اختبار الواجهة. الشرط المقيس **ضيق عمود الدردشة لا ضيق النافذة**: فتح غرفة
العمليات يهبط بـ`#chatColumn` إلى **172px** داخل نافذة 844px، فتقع عتبتا `@container chat-column`
(‏`48rem` ثم `28rem`) بينما لا تقعان عند 844 وحدها.

## العلّتان بالأرقام (قبل — `dist/composer-narrow-before.log`)

| العنصر | المقاس | القياس قبل |
| --- | --- | --- |
| `#engine` | 844×672 + غرفة العمليات | `clientW=69` · `availForText=33` · `textW=160.1` ⇒ **21٪** من اسم المحرك |
| `#engine` | 1280 / 1920 | `137٪` / `102٪` — سليم، ولم يتغيّر بعد الإصلاح |
| `#awarenessBar` | 844×672 + غرفة العمليات | `scrollWidth=305` مقابل `clientWidth=148` ⇒ قصّ صامت يخفي «الأذونات» و«السياق» |

سبب الأول: كتلة `@container chat-column (max-width: 28rem)` تجعل `.composer-tools` شبكة عمودين
(‏`repeat(2, minmax(0, 1fr))`)، فنصف صفٍّ ضيّق أصلاً لا يسع اسم محرك؛ ومعه `.ct-label` مخفية منذ
كتلة `48rem` (‏`aria-label` باقٍ منذ الدفعة أ — `70-accessibility-names.md` — لكن البصري مقصوص).
سبب الثاني: `.awareness-bar { overflow-x: auto }` بلا التفاف ولا تدرّج حافة.

## الإصلاح — الأصغر، ومحصور في كتلة `28rem`

```css
#engine { grid-column: 1 / -1; }                                  /* OBS-168 */
.awareness-bar { flex-wrap: wrap; row-gap: var(--space-1); }      /* OBS-174 */
```

و`src/ui/app.js` في `syncAwareness()`: `title` المنتقي صار **نصّ الخيار المختار** بدل
`"المحرك/المزوّد"` الثابت. **لماذا الاثنان معاً وليس الأصغر وحده**: الصفّ الكامل رفع
`availForText` من 33 إلى **110px** مقابل `textW=160.1` — أي **69٪** فقط، دون عتبة 80٪. فلا CSS
وحدها تكفي ولا ينفع توسيع أكثر داخل 172px؛ الدلالة النصّية هي ما يكشف المحرك المختار يقيناً.
(‏`syncAwareness` نقطة النداء الوحيدة اللازمة: تُستدعى عند الإقلاع وبعد `loadProviders` وعند
تغيير المحرك.)

| `#awarenessBar` | `305/148` (مقصوص) ⇒ **`148/148`** (ملتفّ، صفر مخفي) |
| ارتفاع الشريط | 27 ⇒ **89px** |
| ارتفاع `footer` | 279 ⇒ **372px** (منها +41 للصفّ الكامل و+52 للالتفاف — مقيسة بالعضّة الثانية: 320px) |

**كلفة معلنة**: المؤلّف يأخذ 372 من 672px عند أضيق حالة. قُبلت مقابل بديلها — تدرّج حافة يبقي
الارتفاع 27px لكنه يترك زرّي «الأذونات» و«السياق» خارج الشاشة خلف تمرير أفقي بلا لمس على سطح
المكتب. القرار: **إظهار كل الأزرار أولى من ادّخار 62px** في حالة يكون فيها العمود 172px أصلاً.
لا تغيير بالبكسل عند 1280/1920 (مقيس في الجدول الأول).

## الحارس `test:composer-narrow` (في `SUITE`)

`scripts/composer-narrow-test.js` — Electron حيّ على حاضن TestSprite، يفتح غرفة العمليات
**بزرّها الحقيقي** `#opsRoomToggle` ثم يقيس في 844/1280/1920:

1. `#engine`: `availForText` (‏`clientWidth` ناقص الحشوة المحسوبة وسهم القائمة) مقابل عرض نصّ
   الخيار المختار بـ`canvas.measureText` بخطّ المنتقي الفعلي. يمرّ إن ظهر النصّ **≥ 80٪** **أو**
   إن طابق `title` نصّ الخيار حرفياً — ويُطبع أيّ الشرطين تحقّق (البديلان مقصودان: أحدهما بصري
   والآخر نصّي، وأيّهما تحقّق فالمحرك معروف).
2. `#awarenessBar`: يمرّ إن `scrollWidth <= clientWidth` (التفاف) **أو** بدلالة قصٍّ مقيسة
   (‏`mask-image` غير `none`، أو `::after` بعرض > 0).

**حدّان مُصرَّح بهما**: (١) عرض النصّ مقيس بـ`canvas` لا بالبكسل المرسوم داخل `<select>` (‏Chromium
لا يعرّض صندوق نصّه الداخلي)، فتقدير الحشوة والسهم محافظ تقريبي؛ (٢) الحارس يحكم على القرائية
بالأرقام لا على جمال التخطيط.

## العضّتان (بعد الالتزام، ثم الاستعادة)

| العضّة | الناتج |
| --- | --- |
| إزالة `#engine { grid-column: 1 / -1 }` **و**`title` الديناميكي | سقط: `availForText=33 مقابل textW=160.1 (21٪) وبلا title مطابق — OBS-168` |
| إزالة `flex-wrap: wrap` من `.awareness-bar` | سقط: `scrollWidth=305 مقابل clientWidth=148 بلا دلالة قصّ — OBS-174` |

عُضَّ شقّا OBS-168 معاً عمداً: هما شرطان بديلان في الحارس، فإسقاط أحدهما وحده يبقيه أخضر
بالتصميم (البديل النصّي يكفي) — والعضّة يجب أن تُسقط الحارس لتثبت أنه يقيس العلّة لا شكلها.
