### توصيلات المشروع المجانية (OBS-145 — دفعة الرمز الشخصي، 2026-09-08)

- اللوحة القائمة `/موصلات` تعرض حساب الخدمة والمورد والصلاحيات والمصادقة واختبار
  API وآخر استعمال من المحرك؛ خوادم MCP القديمة في قسم منفصل ولا ترث قيود التوصيلات.
- `electron/connections.js`: نواة مستقلة عن المحرك، هوية المشروع من realpath ومعالجة
  حالة الأحرف على Windows؛ السجلات في `~/.satr/connections/` مشفرة عبر safeStorage.
  لا استعمال لمسار keys.js الذي يسمح تاريخياً بالنص الصريح. الفصل يترك علامة
  خالية من الأسرار لإبطال طلب مصادقة قديم؛ الحساب والرمز والموارد لا تحفظ مكشوفة.
  الكتابة async وتجمع قفل نظام قصير العمر مع علامة ملف ذرية: named pipe في Windows
  وabstract socket في Linux. تُسترد علامة v2 المطابقة بعد موت المالك فقط؛ القديمة
  والمجهولة لا تُحذف. الاسترداد لمخزن محلي يدعم hard links على الجهاز نفسه؛
  UNC وباقي المنصات تبقى على قفل الملف السابق بلا وعد تعافٍ.
  تعذر حفظ lastEngineUse بعد نجاح الخدمة يعيد ok:true وwarning:usage_not_saved
  وusageSaved:false إذا بقيت الملكية صالحة. تبدّل الاتصال يحجب البيانات القديمة؛
  والكتابة التي نجحت خارجياً تُوسم externalOutcome:succeeded وretryable:false.
  [أدلة التعافي والتنافس والعضّات](docs/CONNECTIONS-RECOVERY-EVIDENCE.md).
- `electron/connection-services.js`: GitHub وNetlify وSupabase عبر HTTP أصلي، بلا
  تبعيات جديدة. نطاقات ومسارات وعمليات محددة، منع إعادة التوجيه، انتقاء حقول الرد،
  وحجب الرموز قبل إرجاع نص. لا URL أو SQL عام من النموذج. Supabase للقراءة فقط.
- `electron/connection-ipc.js`: قنوات connectionList/Authenticate/Resources/Select/
  Test/Disconnect عبر غلاف renderertrust نفسه في main؛ preload يكشف دوال محددة فقط.
  يرفض المسار الغائب/النسبي وحقولاً زائدة ومعرّفات مورد غير صالحة. لا قناة تعيد الرمز.
- `electron/connection-tools.js`: الأداتان list_project_connections وuse_project_connection
  مشتركتان بين SDK وCodex/Kimi MCP وREST adapters. ملكية cwd تثبت مع الدور، والنواة
  تعيد فحص revision والمورد والصلاحية قبل الشبكة وبعد الإذن وبعد النتيجة؛ نقل متعدد
  الطلبات يعيد الفحص قبل الطلب التالي. الموافقة على الكتابة لنداء واحد حتى bypass؛
  ليست منحة دائماً ولا للدور. stop/end يبطل البوابة، وKimi يفحص صاحب الدور المستأجر.
- إعداد الاتصال ليس شهادة استعمال محرك. آخر استعمال يسجل عند نجاح أداة ذلك المحرك
  فقط؛ المحوّل الذي يتدهور إلى دردشة بلا أدوات لا يثبت القدرة، وCLI الاحتياطي غير مدعوم.
- OAuth العام لم يكتمل: GitHub Device Flow يحتاج تطبيق سطر مسجلاً، وNetlify يشترط
  OAuth للتكامل العام. هذه دفعة شخصية قابلة للتجربة وليست إطلاقاً عاماً مكتمل المصادقة.
  [الخطة والمصادر والحدود](docs/CONNECTIONS-PLAN.md). الأتمتة والجوال والمبدّل خارجها.
- الحراس: test:connections وtest:connection-services وtest:connections-ui داخل الطقم؛
  probe:connections يستعمل Codex المثبت وطرف خدمة محقون، خارج الطقم لكلفة المحرك.
  لا يثبت المسبار حساباً خارجياً حياً؛ نتيجة التنفيذ والقبول البشري توثقان في الخطة.
