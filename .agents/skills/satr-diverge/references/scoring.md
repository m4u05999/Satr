# مخططات التوليد والنقد

## خرج فرع التباعد

```json
{
  "frame": "security-boundary-auditor",
  "ideas": [
    {
      "id": "F1-I1",
      "text": "وصف قصير للفكرة",
      "mechanism": "الآلية التي تجعلها مختلفة",
      "assumption": "الافتراض الحامل"
    }
  ]
}
```

لا تسمح بنثر خارج JSON. يجب أن يحتوي كل فرع خمس أفكار.

## أبعاد النقد

قيّم كل بعد من 0 إلى 10:

- `N` — الجدة: البعد عن الحل الافتراضي دون غرابة مجانية.
- `V` — القابلية: إمكانية بناء الفكرة وتشغيلها وصيانتها.
- `F` — الملاءمة: مدى حلها للمسألة والقيود الفعلية.
- `E` — الدليل: مقدار دعمها من الكود أو القياس أو عقد موثق.
- `S` — الأمان: حفاظها على حدود الثقة والأذونات والخصوصية.

الدرجة المركبة:

```text
score = 0.20*N + 0.25*V + 0.20*F + 0.20*E + 0.15*S
```

لا تستخدم الدرجة وحدها؛ استبعد الفخاخ قبل الترتيب.

## الفخاخ القاطعة

استبعد المرشح إذا كان نجاحه يتطلب واحداً من الآتي:

- تعطيل `sandbox` أو `contextIsolation` أو توسيع preload بلا عقد محدود.
- تمرير مدخل غير منقّى إلى مسار أو `spawn`.
- تجاوز إذن داخلي أو اعتبار وضع تحكم المتصفح تفويضاً دائماً.
- كسر صيغة حدث مشتركة من دون هجرة وتحديث الأطراف.
- الاعتماد على سلوك غير مثبت لمحرك أو إصدار.
- إضافة اعتماد ثقيل لقيمة يمكن تحقيقها بالمكوّنات الموجودة.
- تجاهل Windows أو العربية أو BiDi في مسار يواجه المستخدم.

## خرج الناقد

```json
{
  "clusters": [
    { "name": "زاوية الآلية", "idea_ids": ["F1-I1", "F3-I2"] }
  ],
  "reviews": [
    {
      "idea_id": "F1-I1",
      "scores": { "N": 8, "V": 7, "F": 9, "E": 3, "S": 8 },
      "trap": false,
      "trap_reason": "",
      "strongest_objection": "أقوى اعتراض قابل للاختبار"
    }
  ]
}
```

## سجل الأدلة

لكل ادعاء مؤثر سجّل:

```json
{
  "claim": "الادعاء",
  "status": "fact | inference | unverified",
  "evidence": ["electron/example.js:42"],
  "impact": "كيف غيّر التقييم"
}
```

المسار والموضع دليل، أما الاستنتاج فيجب أن يبقى موسوماً `inference`.

## خرج التصحيح

```json
{
  "idea_id": "F1-I1",
  "corrected_mechanism": "الآلية بعد النقد والدليل",
  "load_bearing_risk": "الخطر الذي قد يسقط الفكرة",
  "first_reversible_test": "أصغر اختبار قابل للتراجع",
  "stop_condition": "متى نتوقف أو نرفض المرشح",
  "remaining_unknowns": ["مجهول واحد على الأقل"]
}
```

## عرض الدرجات

استخدم شارة موجزة مثل `[N8 V7 F9 E6 S8]`. لا تعرض كسور الدرجة المركبة إلا عند كسر تعادل حقيقي.
