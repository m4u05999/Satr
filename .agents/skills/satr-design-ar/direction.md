# الاتجاه (BiDi) — الفخّ ودليله وإصلاحه

## 1) الفخّ: القرار يُتخذ من أول حرف قوي

`unicode-bidi: plaintext` و`dir="auto"` **لا يقرآن النص**؛ يحسمان الفقرة كلّها بأول
محرف قوي فيها. فالفقرة العربية المفتتحة برمز لاتيني ترسو LTR بأكملها: ينقلب ترتيبها
البصري، وتقفز علامات الترقيم إلى الطرف الخطأ، وتنعكس الأسهم. وهذه أمثلة يومية لا نادرة:

```
SHA-256 لهذا الملف مختلف عن المتوقّع.        ← يسقط: أول قوي هو S
npm run build فشل بسبب ملف مفقود.             ← يسقط: أول قوي هو n
(1) radius-scale أكبر من المتوقّع.            ← يسقط: القوس والرقم ضعيفان، وأول قوي r
"سطر" واجهة عربية.                            ← يمرّ: أول قوي عربي
(1) افتح الإعدادات ثم اختر اللغة.             ← يمرّ: أول قوي عربي
```

**دقّة تحسم المثالين الأخيرين**: الحاسم أول محرف **قوي** (لاتيني أو عربي)؛ أما الأرقام
والترقيم والأقواس والمسافات فضعيفة وتُتخطّى. لذلك `(1) افتح` سليم و`(1) radius-scale`
يسقط. لا تحكم بأول *محرف* بل بأول محرف *قوي*.

القاعدة العملية: **أي نصّ عربي الجوهر أوّلُ كلمةٍ لاتينية فيه تسبق أوّل كلمة عربية هو
مرشّح للعطل** — معرّف، أمر طرفية، اسم دالة، علامة تجارية، وحدة قياس.

## 2) الدليل: البكسل لا الخاصية المحسوبة

`getComputedStyle(el).direction` يعيد `rtl` **الموروثة** حتى وهي فقرة رست LTR فعلياً،
لأن `plaintext` يغيّر الرسوّ لا قيمة الخاصية. الدليل الوحيد: **موضع أول محرف** مقارنةً
بحافتَي العنصر.

المبدأ: احسب `box.right - first.right` و`first.left - box.left`؛ الأصغر يدلّ على حافة
الرسوّ. وإن تساويا (فرق أقل من بكسل) فالنصّ غير حاسم — لا تحكم عليه.

### مسبار يدوي (إن لم تتوفّر `browser_readability`)

الصقه في console الصفحة. قراءة محضة: لا يكتب في DOM.

```js
(()=>{const AR=/[\u0600-\u06FF\u0750-\u077F\u0870-\u089F\u08A0-\u08FF\uFB50-\uFDFF\uFE70-\uFEFF]/g;
const want=s=>{const a=(s.match(AR)||[]).length,l=(s.match(/[A-Za-z]/g)||[]).length;
  return (!a&&!l)?'':(a*2>=l?'rtl':'ltr');};
const bad=[];
document.querySelectorAll('p,li,h1,h2,h3,h4,h5,h6,td,th,blockquote,label').forEach(el=>{
  const t=(el.textContent||'').replace(/\s+/g,' ').trim(); if(t.length<12) return;
  const w=want(t); if(!w) return;
  const walk=document.createTreeWalker(el,NodeFilter.SHOW_TEXT,null); let n,node=null;
  while((n=walk.nextNode())) if(n.data.trim()){node=n;break;}
  if(!node) return;
  const lead=node.data.length-node.data.replace(/^\s+/,'').length;
  if(lead>=node.data.length) return;
  const r=document.createRange(); r.setStart(node,lead); r.setEnd(node,lead+1);
  const f=r.getBoundingClientRect(), b=el.getBoundingClientRect();
  if((!f.width&&!f.height)||(!b.width&&!b.height)) return;
  const dR=b.right-f.right, dL=f.left-b.left;
  if(Math.abs(dR-dL)<1) return;              // غير حاسم
  const got=dR<=dL?'rtl':'ltr';
  if(got!==w) bad.push({want:w,got,text:t.slice(0,40)});
});
console.table(bad); console.log('عدد المخالفات:', bad.length);
})()
```

## 3) الإصلاح: قرار إحصائي لكل عنصر

```js
function textDir(s){
  const ar=(s.match(/[\u0600-\u06FF\u0750-\u077F\u0870-\u089F\u08A0-\u08FF\uFB50-\uFDFF\uFE70-\uFEFF]/g)||[]).length;
  const lat=(s.match(/[A-Za-z]/g)||[]).length;
  if(!ar&&!lat) return '';
  return ar*2>=lat ? 'rtl' : 'ltr';
}
```

النسبة `ar*2 >= lat` متحفّظة عمداً لصالح RTL: فقرة عربية بمعرّفات لاتينية كثيرة تبقى RTL.

**أين تُطبَّق**: على العنصر لحظة إنشائه/تحديث نصّه، بالنصّ **الخام** قبل أي تحويل
Markdown أو HTML — كي لا تحسب وسوم `<strong>` وروابط `href` ضمن الحروف اللاتينية.

```js
function applyDir(el, raw){
  const d = textDir(raw != null ? raw : el.textContent);
  if (d) el.setAttribute('dir', d); else el.removeAttribute('dir');
}
```

في إطار عمل تفاعلي، اجعلها جزءاً من طبقة العرض (خاصية محسوبة/`useMemo`) لا خطّافاً
بعد الرسم؛ وإلا رأى المستخدم ومضة الاتجاه الخطأ.

**كيف تتحقق**: بعد التطبيق، `counts.direction === 0` في `browser_readability`.

## 4) الأساس CSS

```css
html { direction: rtl; }               /* مع <html lang="ar" dir="rtl"> */
p, li, td, th, h1, h2, h3, h4, h5, h6 { unicode-bidi: normal; }
```

**احذف `unicode-bidi: plaintext` من قواعد الفقرات.** إن بقيت، فهي تغلب السمة `dir`
الصريحة التي تضبطها بـ`textDir` ويعود العطل. هذه أكثر النكسات تكراراً بعد الإصلاح.

**كيف تتحقق**: ابحث في CSS عن `plaintext` — يجب ألّا يبقى منها شيء على عناصر تحمل
`dir` محسوباً.

## 5) القوائم: `<bdi>` لا `plaintext`

وضع `unicode-bidi: plaintext` على `<li>` ينقل **صندوق العلامة** (النقطة أو الرقم) إلى
الجهة الخطأ، لأن الاتجاه المحسوب من النصّ يحرّك المُعلِّم معه.

```html
<li><bdi dir="rtl">النصّ هنا</bdi></li>
```

```css
li { direction: rtl; unicode-bidi: normal; }   /* العلامة تبقى يميناً */
li > bdi { display: block; }                    /* كي يأخذ العرض الكامل */
```

`<bdi>` يعزل محتواه، فتضبط `dir` عليه بـ`textDir` بلا أن يتحرّك المُعلِّم.
**كيف تتحقق**: في قائمة مختلطة الاتجاه تصطفّ كل العلامات على حافة واحدة.

## 6) العناوين وخلايا الجداول: أساس ثابت

اختلاف الرسوّ بين خلية وأخرى في العمود الواحد يجعل الجدول غير مقروء. ثبّتها RTL ولا
تستعمل `plaintext` فيها؛ وإن احتاجت خلية محتوى LTR فاعزل المحتوى وحده:

```css
th, td { direction: rtl; text-align: right; }
td .code, td bdi.ltr { direction: ltr; unicode-bidi: isolate; }
```

**كيف تتحقق**: كل خلايا العمود الواحد ترسو على الحافة نفسها.

## 7) الكود المضمّن داخل النثر العربي

```css
code, kbd, samp, var { direction: ltr; unicode-bidi: isolate; }
```

بلا `isolate` يتشوّه المسار داخل الجملة العربية: `src/app/main.js` قد يظهر مقلوب
المقاطع أو تنتقل الشرطة إلى طرفه الخطأ.

**والحالة المرآتية مثلها**: زرّ عربي داخل حاوية LTR يحتاج العزل نفسه، وإلا انزلق نصّه:

```css
.ltr-container :is(.ar-label, bdi[dir="rtl"]) { unicode-bidi: isolate; }
```

**كيف تتحقق**: جملة عربية بداخلها مساران متتاليان — يجب أن يبقى كل مسار كتلة واحدة
متصلة بترتيبه الصحيح.

## 8) الكتل متعددة الأسطر: اتجاه **واحد** للكتلة كلها

تجربة مقيسة: `dir="auto"` **لكل سطر** في عارض ملفات أخفق كاملاً — كل سطر رسا إلى حافة
مختلفة حسب أول محرف فيه، فصار الملف غير مقروء.

القاعدة: كتل الكود والنصوص متعددة الأسطر (`<pre>`, عارض ملف, سجلّ, `diff`) تأخذ
**اتجاهاً واحداً للكتلة**، يُحسم مرة واحدة:

- امتداد كود معروف (`.js`, `.css`, `.py`, `.json`, …) ⇒ `ltr` دائماً.
- غير ذلك ⇒ `textDir()` على **مجموع** نصّ الكتلة.

```css
pre { unicode-bidi: normal; white-space: pre; }
pre[dir="ltr"] { direction: ltr; text-align: left; }
pre[dir="rtl"] { direction: rtl; text-align: right; }
```

**كيف تتحقق**: كل أسطر الكتلة ترسو على الحافة نفسها بلا استثناء.

## 9) التخطيط المرآتي: `dir` وحدها لا تكفي

عمودان (أرقام أسطر + نصّ) لا ينعكسان بـ`dir` وحدها، لأن **الوراثة تغلب `dir`**:
`text-align: left` موروثة تبقى فاعلة داخل حاوية `rtl`.

```css
.row { display: flex; flex-direction: row-reverse; }  /* الأرقام تنتقل يميناً */
.row .text { text-align: right; }                     /* صريحة — لا تعتمد على الوراثة */
```

**كيف تتحقق**: بدّل `dir` على الجذر وقارن اللقطتين؛ ما لم ينعكس يحمل قاعدة موروثة.

## 10) الخصائص المنطقية بدل الفيزيائية

استبدل الفيزيائية بالمنطقية فتنعكس تلقائياً مع `dir`:

| فيزيائية | منطقية |
|---|---|
| `margin-left` | `margin-inline-start` |
| `padding-right` | `padding-inline-end` |
| `left: 0` | `inset-inline-start: 0` |
| `border-left` | `border-inline-start` |
| `text-align: left` | `text-align: start` |

**كيف تتحقق**: ابحث في CSS عن `-left`/`-right`/`text-align: left` — كل نتيجة مرشّحة عطل
مرآة. الحسم: لقطتان بـ`dir="ltr"` ثم `dir="rtl"`؛ ما لم ينعكس هو العطل.

استثناءات مشروعة تبقى فيزيائية: ما لا ينعكس بطبيعته (شعار في زاوية ثابتة بقرار تصميمي،
محاور مخطّط بيانات ذات معنى مطلق).

## 11) الأيقونات: ما ينعكس وما لا ينعكس

| ينعكس | لا ينعكس |
|---|---|
| أسهم الاتجاه (`→`, `←`, رجوع/تقدّم) | تشغيل ▶ (عرف عالمي مرتبط بشريط الزمن) |
| مؤشّر «التالي/السابق» | بحث 🔍، إغلاق ✕، إعدادات ⚙ |
| شريط التقدّم واتجاه امتلائه | الساعة، الشعارات، أيقونات العلامات التجارية |
| مسافة بادئة/شجرة، سهم الطيّ | الأرقام والرموز الرياضية |

```css
[dir="rtl"] .icon-arrow { transform: scaleX(-1); }
```

انتبه: انعكاس السهم يجب أن يصاحبه انعكاس **الدلالة** في الكود (زرّ «التالي» يشير
يساراً في RTL). سهمٌ انعكس شكلاً وبقي يستدعي `next()` بمنطق LTR عطلٌ مضاعف.

**كيف تتحقق**: انقر زرّ «التالي» في RTL — يجب أن ينتقل إلى العنصر التالي فعلاً.

## 12) الإدخال والتحرير

- **استعمل `<textarea>` لا `contenteditable`** حين تهمّ صحّة الإدخال العربي (IME):
  الأول يعطي تراجع/إعادة أصليين وتركيباً سليماً؛ والثاني يكسر تسلسل التركيب ويجعل
  استخراج النصّ من الشجرة هشّاً.
- الحقل يرث `dir` من الحاوية؛ لحقل قد يستقبل الاتجاهين استعمل `dir="auto"` **على الحقل
  وحده** (هنا الفخّ محتمَل لكن البديل — قفل الاتجاه — أسوأ لأن المستخدم يرى ما يكتب).
- **الترميز**: حفظ ملف بترميز ANSI بلا BOM يُفسد العربية. اكتب دائماً UTF-8، وتحقّق
  بإعادة قراءة الملف ومطابقة النصّ لا بالنظر إلى المحرّر.
