# قائمة ما قبل الإطلاق — كل بند ومعه كيف تكذّبه

بندٌ لا تعرف كيف تتحقق منه ليس بنداً بل أمنية. إن لم تستطع تنفيذ عمود «كيف تتحقق»
فاشطب البند من تقريرك بدل تمريره.

## 0) الأساس (قبل أي شيء)

| البند | كيف تتحقق |
|---|---|
| الصفحة مفتوحة في المعاينة فعلاً | `browser_readability` يعيد `url` مطابقاً لما تقصد |
| `<html lang>` مضبوط بـ`locale` صحيح | التقرير يعيد `lang` غير فارغ ومطابقاً |
| `<html dir="rtl">` مضبوط | التقرير يعيد `doc_dir === 'rtl'` |
| تعرف ما لم يُفحَص | اقرأ `unseen.shadow_roots` و`unseen.iframes` و`truncated` |

## 1) الاتجاه

| البند | كيف تتحقق |
|---|---|
| لا رسوّ مقلوب | `counts.direction === 0` |
| لا `unicode-bidi: plaintext` على فقرات تحمل `dir` محسوباً | بحث نصّي في CSS عن `plaintext` |
| `dir` مشتقّ إحصائياً لا من أول حرف | افحص عنصراً نصّه يبدأ بـ`npm …` وبقيته عربية ⇒ `dir="rtl"` |
| علامات القوائم على حافة واحدة | قائمة مختلطة الاتجاه: كل النقاط/الأرقام على جهة واحدة |
| المسارات داخل النثر لا تتشوّه | جملة عربية بمسارين متتاليين — كلٌّ كتلة متصلة صحيحة الترتيب |
| كتل الكود باتجاه واحد للكتلة | كل أسطر `<pre>` ترسو على الحافة نفسها |
| التخطيط ينعكس فعلاً | لقطتان بـ`dir=ltr` و`dir=rtl` — قارنهما، ما لم ينعكس فيه قاعدة فيزيائية |
| الأسهم تنعكس شكلاً **ومعنى** | انقر «التالي» في RTL: هل ينتقل إلى التالي فعلاً؟ |

## 2) الخط

| البند | كيف تتحقق |
|---|---|
| الخط محمّل لا مُسمّى فقط | `counts.font === 0` |
| الأسرة المستضافة أولاً في المكدّس | `font_stacks` في التقرير — أول اسم هو أسرتك |
| الأوزان المستعملة محمّلة فعلاً | `document.fonts.check('700 16px MyFont')` ⇒ `true` |
| `unicode-range` يشمل `U+200C` | افحص كتلة `@font-face` — بلا هذا ينكسر تشكيل الفارسية/الأردية |
| لا `letter-spacing` موجب على نصّ عربي | بحث في CSS + نظرة: كلمة «مكتبة» متّصلة بلا فراغ داخلي |
| لا وزن مصطنع (faux bold) | `document.fonts.check` للوزن المستعمل — إن `false` فهو مصطنع |
| مقاس الأساس ≥ 16px | `getComputedStyle(document.body).fontSize` |
| ارتفاع السطر 1.6–1.7 (عرف لا عتبة مقيسة) | `getComputedStyle(el).lineHeight` مقسوماً على `fontSize` — وإن خالفتَه فاذكر لماذا |

## 3) التباين

| البند | كيف تتحقق |
|---|---|
| لا مخالفة تباين مرصودة | `counts.contrast === 0` |
| النصّ فوق التدرّجات والصور فُحص يدوياً | الأداة **تتخطّاه** — قِسه بنفسك أو صرّح بأنه غير مفحوص |
| لا دورة في متغيّرات CSS | متغيّر يعيد تعريف نفسه بـ`var(--x)` احتياطاً لنفسه ينهار؛ استعمل `inherit` |
| الوضعان الفاتح والداكن مفحوصان | بدّل الثيمة وأعد `browser_readability` — التقرير للحالة المعروضة فقط |

## 4) التخطيط والتجاوز

| البند | كيف تتحقق |
|---|---|
| لا تمرير أفقي | `counts.overflow === 0` و`page_overflow === null` |
| فُحص عند عرض ضيق | `browser_set_viewport` لعرض ضيق ثم أعد القياس |
| فُحص عند عرض واسع | كرّر عند عرض واسع — العطلان مختلفان |
| العرض المقيس هو ما طلبته | `viewport.width` مطابق؛ إن ظهر `overridden` أو `device_mode` فقد قُصَّ طلبك |

## 5) اللغة والمحتوى

| البند | كيف تتحقق |
|---|---|
| ZWNJ ينجو من كل طبقات المعالجة | `sanitize(s) === s` لكلمة فارسية تحوي `U+200C` |
| لا تطبيع مُفسد للياء/الكاف في العرض أو الحفظ | بحث في الكود عن تحويل `U+06CC`/`U+06A9` |
| نظام أرقام واحد لكل سياق | لقطة لصفحة فيها أرقام في ثلاثة مواضع |
| صيغ الجمع العربية الستّ مغطّاة | اعرض العدّاد عند `0,1,2,3,11,100` |
| أسماء اللغات ذاتية | منتقي اللغة يعرض `فارسی` لا `Persian` |
| الإدخال العربي سليم | اكتب عربية في الحقل بلوحة مفاتيح عربية — لا حروف منفصلة ولا ترتيب مقلوب |
| الملفات محفوظة UTF-8 | أعد قراءة الملف وطابق النصّ برمجياً، لا بالنظر في المحرّر |

## 6) الإعلان النهائي (لا تتخطّه)

لا تُنهِ العمل بجملة «الواجهة العربية سليمة». اكتب بدلها أربعة أشياء:

1. **العرض/العروض** التي قِست عندها.
2. **العدّادات الأربعة** كما عادت.
3. **ما لم يُفحص**: عدد جذور Shadow و`<iframe>`، وهل `truncated` صحيح، وهل هناك نصّ
   في `div`/`span`/`button` خارج نطاق الفحص.
4. **ما لم يُقَس أصلاً**: جودة تشكيل الحروف، والجمال، وترخيص الخط، وصحة الترجمة.

صيغة صالحة للنسخ:

> قِست عند 390px و1280px. العدّادات: اتجاه 0، خط 0، تباين 0، تجاوز 0 — على 47 عنصراً
> مفحوصاً (`truncated: false`). **لم يُفحص**: جذر Shadow واحد، و`<iframe>` واحد، وكل
> النصوص داخل `div` لأن الفحص يطال عناصر الكتل فقط. **لم يُقَس**: جودة تشكيل الحروف
> والملاءمة البصرية — تحتاج عيناً تقرأ اللغة.
