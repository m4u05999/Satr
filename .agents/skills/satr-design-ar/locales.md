# عائلة الحرف العربي — اللغة مفتاحها `locale` لا «أسرة خط»

## 1) الجدول

| `locale` | الاسم الذاتي | محارف فارقة | الأرقام الشائعة |
|---|---|---|---|
| `ar` | العربية | — (الأساس) | `٠١٢٣٤٥٦٧٨٩` مشرقاً · `0123456789` مغرباً |
| `fa-IR` | فارسی | `پ چ ژ گ ک ی` | `۰۱۲۳۴۵۶۷۸۹` |
| `fa-AF` | دری | نفس `fa-IR` تماماً | `۰۱۲۳۴۵۶۷۸۹` |
| `ur` | اردو | `ٹ ڈ ڑ ں ھ ے` | `۰۱۲۳۴۵۶۷۸۹` |
| `ps` | پښتو | `ټ ځ څ ډ ړ ږ ګ ڼ ۍ ې` | `۰۱۲۳۴۵۶۷۸۹` |
| `ckb` | کوردی | `ڕ ڵ ێ ۆ ھ` | `۰۱۲۳۴۵۶۷۸۹` |
| `sd` | سنڌي | `ٻ ڀ ٺ ٽ ڦ ڻ ڄ ڃ` | `۰۱۲۳۴۵۶۷۸۹` |
| `ug` | ئۇيغۇرچە | `ئ ۈ ۆ ڭ ې` | `0123456789` غالباً |

**الأرقام في هذا الجدول إشارة لا حكم**: العرف يختلف بالبلد والسياق (الأرقام اللاتينية
شائعة في واجهات عربية حديثة كثيرة). **اسأل المستخدم أو ناطقاً**؛ فائدة العمود أن يمنع
**الخلط داخل الرقم الواحد**، لا أن يفصل في العرف.

**سِمِّ اللغة باسمها الذاتي في منتقي اللغة** — لا «Persian» ولا «الفارسية» لمن يقرأ
`فارسی`. الاسم الذاتي هو ما يتعرّف عليه صاحب اللغة فوراً.

## 2) `fa-AF` مقابل `fa-IR`: صفر فرق تقني

الدرية (أفغانستان) والفارسية (إيران) **لا تختلفان** على أي مستوى يهمّ الواجهة: نفس
الاتجاه، ونفس متجه المحارف، ونفس متطلّبات الخط، ونفس المقاييس الرأسية. الفرق **معجمي
وأسلوبي** (مفردات وتعابير)، لا شكلي.

**النتيجة الهندسية**: لا تبنِ آلية خطوط أو تخطيط لكل لغة. ابنِ آلية **محتوى ووسوم**
لكل `locale`: ملفّ ترجمة، وتسمية، وصيغة أرقام وتاريخ. أي كود يفرّع على «اللغة» ليختار
خطاً مختلفاً بين `fa-AF` و`fa-IR` هو تعقيد بلا مقابل.

## 3) عدّ نطاق Unicode لا يثبت أن الصفحة عربية

فخّ مقيس: فحصٌ ساذج «هل في الصفحة محارف في `U+0600–06FF`؟» يجعل **صفحة فارسية خالصة**
تُصنَّف «عربية مطابقة تماماً». النطاق يدلّ على **الكتابة (script)** لا على **اللغة**.

- لتقرير الاتجاه والخط: النطاق **يكفي** (وهو ما تفعله `textDir` عن قصد).
- لتقرير **اللغة**: النطاق **لا يكفي أبداً**. المصدر هو `<html lang>` أو تفضيل المستخدم
  أو `Accept-Language` — لا التخمين من المحارف.

المحارف الفارقة في الجدول أعلاه تعطي **إشارة** (وجود `ٹ ڈ ڑ` يرجّح الأردية) لكنها لا
تحسم: نصّ فارسي فيه اقتباس أردي يحوي المحرفين معاً. لا تبنِ قراراً حاسماً عليها.

**كيف تتحقق**: `browser_readability` يعيد `lang` و`doc_dir`. `lang` فارغ = عطل صريح
يُصلَح بـ`<html lang="fa-IR" dir="rtl">`.

## 4) ZWNJ — الفاصل الصفري (`U+200C`)

في الفارسية والأردية والبشتو، `U+200C` (ZERO WIDTH NON-JOINER) **محرف ذو معنى**، لا
مسافة تُنظَّف: يمنع اتصال حرفين مع بقائهما كلمة واحدة.

```
می‌روم    (بـZWNJ)   ← الصواب: «أذهب»
میروم     (بلا ZWNJ) ← اتصال خاطئ، شكل الكلمة مختلف
```

**ثلاثة أماكن يُقتل فيها ZWNJ صامتاً**:
1. دوال التنقية: `replace(/[\u200B-\u200F]/g,'')` تحذف ZWNJ مع محارف Bidi. **استثنِ
   `U+200C` صراحةً** إن كنت تنظّف محارف التحكّم.
2. `unicode-range` في `@font-face` لا يشمل `U+200C` ⇒ يُرسم من خط آخر فينكسر التشكيل.
3. «التطبيع» قبل البحث أو المقارنة: طبّع نسخةَ الفهرسة فقط، واحفظ الأصل كما هو.

**كيف تتحقق (فحص حاسم)**:
```js
const s = 'می‌روم';
s.includes('\u200C')          // يجب أن يبقى true بعد المرور بكل طبقات معالجتك
sanitize(s) === s             // أي تنقية يجب أن تُبقيه
```

## 5) فخّ التطبيع: الياء والكاف الفارسيتان

| المحرف | النقطة | تُستعمل في |
|---|---|---|
| `ي` | `U+064A` | العربية |
| `ی` | `U+06CC` | الفارسية · الأردية · السورانية |
| `ك` | `U+0643` | العربية |
| `ک` | `U+06A9` | الفارسية · الأردية · السورانية |

كثير من دوال «التطبيع العربي» تحوّل `ی → ي` و`ک → ك`. هذا **صحيح** لتطبيع بحثٍ عربي،
و**مُفسِد** إن طُبِّق على نصّ فارسي معروض أو مخزَّن: يقلبه إلى شكل ليس لغته.

**القاعدة**: طبّع للمقارنة والفهرسة فقط، على نسخة، وبشرط `locale`. لا تطبّع ما يُعرض
ولا ما يُحفظ.

**كيف تتحقق**: ابحث في الكود عن `ی` و`ک` و`u064A` و`0643`؛ كل تحويل بينها
في مسار عرض أو حفظ عطلٌ محتمل.

## 6) الأرقام والتواريخ والفرز — استعمل `Intl` لا جداول يدوية

```js
new Intl.NumberFormat('fa-IR').format(1234)     // '۱٬۲۳۴'
new Intl.NumberFormat('ar-EG').format(1234)     // '١٬٢٣٤'
new Intl.NumberFormat('ar-MA').format(1234)     // '1.234'
new Intl.NumberFormat('ar', {numberingSystem:'latn'}).format(1234)  // فرض لاتيني
```

**لا تخلط داخل الرقم الواحد** (`١٢34`) ولا داخل الجدول الواحد. اختر نظاماً للسياق
كلّه وثبّته.

**صيغ الجمع — فخّ حقيقي**: العربية لها **ستّ** صيغ جمع في CLDR، بينما الفارسية
والأردية لهما اثنتان. أي كود يفترض `n === 1 ? 'مفرد' : 'جمع'` مكسور للعربية.

```js
new Intl.PluralRules('ar').select(0)   // 'zero'
new Intl.PluralRules('ar').select(1)   // 'one'
new Intl.PluralRules('ar').select(2)   // 'two'
new Intl.PluralRules('ar').select(3)   // 'few'
new Intl.PluralRules('ar').select(11)  // 'many'
new Intl.PluralRules('ar').select(100) // 'other'
new Intl.PluralRules('fa').select(3)   // 'other'  — صيغتان فقط
```

**كيف تتحقق**: اعرض عدّاداً بالقيم `0, 1, 2, 3, 11, 100` واقرأ الستّ. إن تطابقت
صيغتان يجب أن تختلفا فملفّ الترجمة ناقص.

**التاريخ**: قد يحتاج المستخدم العربي التقويم الهجري.
```js
new Intl.DateTimeFormat('ar-SA-u-ca-islamic').format(new Date())
```
لا تفترض التقويم — اسأل أو اتبع `locale` كاملاً.

## 7) الفرز والمقارنة — `Intl.Collator` بديلاً عن التطبيع المُفسِد

**تصحيح شائع**: كتلة العربية في Unicode مرتّبة أبجدياً أصلاً، فـ`[...].sort()` العادي
يعطي ترتيباً يبدو صحيحاً في الحالات البسيطة. القيمة الحقيقية لـ`Collator` ليست الترتيب
بل **معادلة المتغيّرات** — وهي حلّ المشكلة التي حذّرت منها الفقرة 5 بلا إفساد النصّ:

```js
const c = new Intl.Collator('ar', { sensitivity: 'base' });
c.compare('احمد', 'أحمد')   // 0  — همزات الألف تتساوى
c.compare('مصر',  'مِصر')   // 0  — التشكيل يُتجاهل
c.compare('على',  'علي')    // 0  — الألف المقصورة والياء تتساويان

const f = new Intl.Collator('fa', { sensitivity: 'base' });
f.compare('ی', 'ي')          // 0  — الياء الفارسية والعربية
f.compare('ک', 'ك')          // 0  — الكاف الفارسية والعربية
```

**هذا يغني عن دالة «التطبيع العربي» اليدوية بالكامل** في البحث والمقارنة وإزالة
التكرار — بلا تحويل محرف واحد في النصّ المخزَّن أو المعروض.

**حدّان مقيسان، اعرفهما قبل أن تعتمد**:
- **التاء المربوطة لا تتساوى بالهاء** حتى عند `base`: ‏`compare('فاطمة','فاطمه') = -1`.
  إن أردت معادلتهما في البحث فهي الحالة الوحيدة التي تحتاج فيها معالجة صريحة.
- `sensitivity: 'accent'` يتجاهل التشكيل ويميّز الهمزات؛ و`'variant'` (الافتراضي)
  يميّز كل شيء. اختر بوعي: `base` للبحث، والافتراضي للترتيب النهائي المعروض.

**كيف تتحقق**: شغّل الأسطر أعلاه — كل سطر يعيد رقماً يمكن أن يخالف المكتوب.

## 8) قائمة تحقّق للّغة

| الادّعاء | كيف تكذّبه |
|---|---|
| «الوسوم صحيحة» | `browser_readability` ⇒ `lang` و`doc_dir` غير فارغين وصحيحان |
| «ZWNJ سليم» | `sanitize('می‌روم')` يطابق الأصل |
| «لا تطبيع مُفسد» | بحث في الكود عن تحويل `U+06CC`/`U+06A9` في مسار عرض أو حفظ |
| «الأرقام متّسقة» | لقطة لصفحة فيها أرقام في ثلاثة مواضع — نظام واحد |
| «الجمع صحيح» | عرض العدّاد عند `0,1,2,3,11,100` بالعربية |
| «الأسماء ذاتية» | منتقي اللغة يعرض `فارسی` لا `Persian` |
